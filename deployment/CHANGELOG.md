# 功能修改记录

## 2026-11-06：高清可视化与坐标翻转修复

- 将俯视导出升级到可配置的 3600×3000 像素；保留 DPI、覆盖透明度、颜色与轨迹线宽控制。
- 彩色 mesh 底图从随机 50 万散点改为全顶点的米制栅格颜色聚合，默认约 6 cm/像素，并对颜色总和与权重分别平滑，减轻碎点与背景泛白。
- 修复底图行方向与世界 Z 轴不一致的问题。图像第一行对应 Z 最大侧，第一列对应 X 最小侧；加入非对称四角回归用例，并修正边界点遗漏。
- 新增原始底图 PNG、坐标 JSON，以及 YAML 控制的局部高清放大图。
- 新增 `--visualize-only`，复用已有路线与 NavMesh 刷新可视化，不重复生成视频、不重新烘焙。
- 独立刷新入口可生成真实 Habitat-GS 高斯俯视 RGB，并按每个 NavMesh 顶点的高度做同相机透视投影叠加。
- 忽略全密度资产与本地输出目录，禁止提交原始 PLY、视频和大型生成文件。

验证：语法检查、`git diff --check`、四角坐标回归测试通过；使用全密度场景完成全场及三张局部图生成，核对道路与 NavMesh 对齐。

已知限制：高空高斯俯视拉丝明显，不能用其验证精细障碍；mesh 颜色聚合不是带深度遮挡的正射产品；低柱和树冠是否误判仍需几何核验。本次没有改变碰撞 mesh、正式 NavMesh 或重新生成 50 条视频。
